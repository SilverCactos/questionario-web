Antes de pular de cabeça na programação em Python é bom ter na cabeça alguns conceitos e conhecimentos, neste resumos você vai ver todos eles.

Uma das coisas importantes de se saber é o que forma uma linguagem, não só a linguagem de programação como todas as linguagens que usamos. Toda linguagem precisa dos seguintes elementos: sintaxe, sêmantica, um alfabeto e um léxico.

Sintaxe é o conjunto de regras que define como escrever corretamente em uma linguagem. Exemplo: em Python, print("Olá") tem uma sintaxe válida, enquanto print "Olá" não tem.

Semântica é o significado que um código ou frase possui dentro de uma linguagem. Um código pode estar escrito corretamente (sintaxe certa), mas ter um significado errado.

O alfabeto é o conjunto de símbolos e caracteres que uma linguagem permite usar. Em programação, inclui letras, números e símbolos como +, =, {}, ().

O léxico é o conjunto de palavras e símbolos que possuem significado dentro de uma linguagem. Em Python, palavras como if, while, def e print fazem parte do léxico da linguagem.

Para avançar nos estudos de Python, também é importante entender o que é um código de máquina. Ele é o conjunto de instruções em linguagem binária que o processador consegue interpretar diretamente. Todos os programas que escrevemos em linguagens de programação precisam, em algum momento, ser convertidos para uma forma que o computador consiga executar. Esse processo transforma o código escrito pelos programadores, que é uma linguagem mais próxima da nossa compreensão, em instruções representadas por bits (0 e 1) que podem ser entendidas pela máquina.

Além disso é importante saber tambem a diferença entre um codigo compilado e um codigo interpretado, código compilado é aquele que passa por um processo de tradução completo antes de ser executado, no qual um compilador transforma o código-fonte escrito pelo programador em um código de máquina que o computador consegue entender diretamente. Isso geralmente gera programas mais rápidos na execução, pois a tradução já foi feita previamente. Já o código interpretado é executado por um interpretador, que lê e traduz o código linha por linha durante a execução, sem criar um arquivo de máquina completo antes. Esse processo costuma facilitar testes e alterações no código, mas pode ser mais lento porque a tradução acontece enquanto o programa roda.
